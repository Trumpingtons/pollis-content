# Pollis content

The vignettes, workflows and benchmarks of [Pollis](https://pollis.org) that can be updated between releases. Pollis reads `content.toml` once a day and downloads the entries that are new, or updated since its release, checking each file against its SHA-256.

The list and the files are written by `scripts/pollis-content.jl` in the Pollis repository; do not edit them by hand.
